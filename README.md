# UTAU2DECtalk
This python script converts UTAU UST files to a string for DECtalk and runs DECtalk if available. I get DECtalk from here: https://github.com/dectalk/dectalk
<br />
By default, the say binary is expected at ./dectalk/say
<br />
The provided script "get_dectalk.sh" will automatically download and extract DECtalk for linux.
