# UTAU2DECtalk
This python script converts UTAU UST files to a string for DECtalk and runs DECtalk if available. <br />
<br />
The provided bash script "get_dectalk.sh" will automatically download and extract DECtalk for linux. <br />
<br />
I get DECtalk from here: https://github.com/dectalk/dectalk <br />
<br />
By default, the say binary is expected at ./dectalk/say <br />
